# 🥗 NutriTrack AI

> **Smart nutrition and health tracking with AI-powered insights.**

NutriTrack AI is a modern web application designed to help users track their daily nutrition, food intake, water consumption, physical activity, and health-related information in one place.

The project combines a clean dashboard experience with AI assistance to make personal health tracking easier and more interactive.

## 🌐 Live Demo

**[NutriTrack AI](https://nutritrack-m3ik60knc-tharun-debug2006.vercel.app/)**

## 📌 Features

### 📊 Dashboard

* View daily nutrition progress
* Track calories and macronutrients
* Monitor daily health activities
* Quick overview of important statistics

### 🍎 Food Tracking

* Search and add food items
* Track nutritional information
* Maintain daily food records
* View calorie and nutrient intake

### 💧 Water Tracking

* Record daily water consumption
* Monitor hydration progress
* Track water intake throughout the day

### 🏃 Activity Tracking

* Record physical activities
* Track activity-related information
* Monitor daily progress

### 📅 History

* Review previously recorded nutrition and activity data
* Keep track of progress over time

### 👤 Profile

* Manage personal information
* Store health-related profile details
* Customize tracking information

### 🤖 AI Chatbot

* AI-powered health and nutrition assistance
* Ask questions related to nutrition and healthy habits
* Chatbot can be opened when the user needs assistance

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Tharun-debug2006/NutritrackAI.git
```

### 2. Navigate to the project

```bash
cd NutritrackAI
```

### 3. Install dependencies

Using npm:

```bash
npm install
```

Or using Bun:

```bash
bun install
```

### 4. Start the development server

```bash
npm run dev
```

Or:

```bash
bun run dev
```

The application will be available at the local development URL provided by Vite.

## 🔐 Environment Variables
